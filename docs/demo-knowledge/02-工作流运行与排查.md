# 工作流运行与排查

## 运行状态

工作流运行状态包括等待中、运行中、成功、部分成功和失败。进入“运行记录”后可以按运行编号查看每个节点的输入摘要、输出摘要、耗时和错误码。

失败重试不会从第一个节点重新执行，而是从第一个失败且允许重试的节点继续。含付款、发信或写数据库等副作用的节点默认禁止自动重试，避免重复操作。

## 错误码 WF-50012

`WF-50012` 表示节点执行超过配置的超时时间。先检查节点超时配置和下游服务响应时间，再确认请求体是否过大。单节点最大执行时间为 120 秒，超过该限制应将长任务改为异步回调模式。

修改超时后只对新运行生效。历史失败运行可在详情页点击“从失败节点重试”。如果同一节点连续三次超时，应记录运行编号、节点名称和下游接口耗时并提交故障工单。

## 工作流没有被触发

定时触发器使用工作空间时区。Webhook 触发器必须处于启用状态，草稿版本不会接收生产事件。请检查工作流已发布、触发器已启用、事件时间与工作空间时区，以及运行记录中是否存在被过滤的事件。
