# 第三方连接器

## 数据库连接器

数据库连接器支持 PostgreSQL 14 及以上版本和 MySQL 8。生产环境建议创建只具备所需表权限的专用账号，不要使用数据库管理员账号。

错误码 `CONN-30021` 表示网络连接超时。请检查数据库允许 FlowPilot 出口 IP、端口是否开放、TLS 配置是否匹配。连接测试成功但工作流失败时，还需要检查运行服务账号对目标表的权限。

## 企业微信连接器

企业微信连接器需要企业 ID、应用 AgentId 和 Secret。Secret 只保存在加密配置中，客服人员不会要求客户通过聊天发送 Secret。

应用必须具备通讯录或消息接口对应权限，并处于可见范围。错误码 `CONN-40110` 表示第三方平台拒绝授权，应在企业微信管理后台检查应用权限和可信 IP。

## 连接器凭证轮换

凭证轮换时可以先创建新凭证并测试，再将工作流切换到新版本。确认所有生产工作流切换完成后再停用旧凭证，避免直接覆盖造成批量运行失败。
