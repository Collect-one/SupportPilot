# 账号与工作空间

## 登录与账号锁定

FlowPilot 连续 5 次输入错误密码后会锁定账号 15 分钟。客户可以等待自动解锁，或在登录页选择“忘记密码”发送重置邮件。人工支持不会索要密码，也不能查看用户原密码。

如果没有收到重置邮件，请先检查垃圾邮件，并确认邮箱域名允许接收 `notify.flowpilot.example` 的邮件。超过 10 分钟仍未收到时，应提交账号类工单，并提供企业名称和登录邮箱，不要提供密码。

## 工作空间与成员

每个客户企业可以创建多个工作空间。工作空间编号显示在“设置 > 基本信息”，格式为 `ws_` 加 12 位字符。普通成员不能邀请管理员，也不能修改企业级安全策略。

移除成员不会删除该成员创建的工作流，但其个人 API Token 会立即失效。生产工作流不应依赖个人 Token，应改用服务账号。

## 错误码 40103

错误码 `40103` 表示当前访问凭证没有目标工作空间的权限。请依次检查：请求中的工作空间编号是否正确；Token 所属用户是否仍在该工作空间；Token 是否具备 `workflow:read` 或所需权限。

如果刚调整权限，请重新签发 Token，不要在聊天或工单中粘贴完整 Token。权限同步通常立即生效，客户端仍报错时应清理本地缓存并重新请求。
