# 套餐、配额与计费

## 套餐配额

标准版每个工作空间每月包含 50,000 次节点执行，专业版包含 300,000 次。一次工作流运行会按照实际执行的节点数量计费，因条件分支跳过的节点不计入执行次数。

配额页面可能有最多 10 分钟统计延迟。达到 80% 和 100% 时，系统分别向企业管理员发送提醒。超出配额后，新的非关键工作流会暂停，已有运行不会被中途终止。

## 账单问题

账单按企业统一结算，客户可以在“企业设置 > 账单”下载月度明细。人工支持可以解释计费规则，但不能在未审批的情况下承诺退款、减免或修改合同价格。

如认为节点执行次数异常，应提交计费类工单，并提供账单月份、工作空间编号和相关工作流编号。不要在工单中提交银行卡号或身份证信息。
